# Clarity — การประเมินที่ชัดเจน

## Concept snapshot

| Item | Direction |
|---|---|
| **Concept name** | Clarity / การประเมินที่ชัดเจน |
| **One-sentence description** | A restrained assessment experience prioritizes comprehension, accessibility, and audit-ready recommendations. |
| **Main idea** | A credible school-ready assessment for institutions that value clarity and low cognitive load. |
| **Target user group** | Thai students in ม.3–ม.6, schools, counselors, and parents seeking a formal but humane tool. |
| **Main user problem** | Guidance products often look entertaining but lack institutional trust and accessibility. |
| **Unique value proposition** | A calm, accessible assessment with transparent evidence, confidence, and next actions. |
| **Emotional experience** | Focused, respected, clear, and secure. |
| **Visual direction** | Swiss-inspired grid, warm white, restrained teal, sharp type hierarchy, and almost no decoration. |
| **Development difficulty** | Low–Medium |
| **Recommended technology** | Server-rendered Next.js, semantic forms, FastAPI, PostgreSQL, rule engine, optional RAG explanations. |

## Main features

- Accessible assessment
- Save and return
- Evidence report
- Route comparison table
- Print/PDF view
- Audit notes
- Role-based summary

## Advantages

- Easiest to build and maintain
- Highest accessibility potential
- Strong institutional credibility

## Disadvantages

- Lower novelty and emotional appeal
- May feel too formal for younger users

## Why this fits Future Me

It provides the clearest delivery vehicle for explainable, non-guaranteed guidance and privacy controls.

## Product positioning

**Category:** Minimal professional assessment  
**Promise:** A calm, accessible assessment with transparent evidence, confidence, and next actions.  
**Primary CTA:** เริ่มการประเมิน  
**Voice:** Plain, respectful, concise, and specific.

## Distinct interaction model

Linear assessment with save-and-return, keyboard-first controls, and explicit progress.

### Navigation structure

Utility navigation: Assessment, Report, Plan, Saved, Account.

- Desktop: Simple text navigation in a strict twelve-column grid.
- Mobile: Plain labeled tabs; no icon-only controls.

### Core layouts

- **Homepage:** Minimal asymmetric grid with abundant whitespace and one precise generated still life.
- **AI interview:** A structured prompt-and-response workspace with transcript control and evidence review.
- **Dashboard:** A report-like dashboard with clear sections, tables, next action, and update date.
- **Results:** Accessible comparison table plus route dossiers and confidence/caveat notes.
- **Roadmap:** Numbered milestone list with prerequisites, dates, and print-friendly formatting.

## Design guardrails

- Present routes as hypotheses for educational exploration, never guaranteed predictions.
- Keep private chat content separate from any parent/teacher summary.
- Keep official admissions facts, source dates, and assumptions distinguishable.
- Offer a list alternative to any graph, map, or highly visual interaction.
- Make “ยังไม่รู้” and “แก้ไขสิ่งที่ AI เข้าใจ” first-class actions.
