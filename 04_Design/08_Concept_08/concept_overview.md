# Skill Constellation — จักรวาลทักษะของฉัน

## Concept snapshot

| Item | Direction |
|---|---|
| **Concept name** | Skill Constellation / จักรวาลทักษะของฉัน |
| **One-sentence description** | A living network connects interests, demonstrated skills, values, courses, and career clusters. |
| **Main idea** | A visual mapping tool for students with cross-disciplinary interests. |
| **Target user group** | Thai upper-secondary, vocational, and university students with several overlapping interests. |
| **Main user problem** | Linear career lists hide transferable skills and hybrid routes. |
| **Unique value proposition** | See how one proven skill opens several education and career neighborhoods. |
| **Emotional experience** | Expansive, curious, intelligent, and free from fixed labels. |
| **Visual direction** | Deep indigo space, luminous glass nodes, elegant data-art, and connected clusters. |
| **Development difficulty** | Very High |
| **Recommended technology** | Next.js, WebGL/SVG graph renderer, graph service, PostgreSQL/graph tables, Qdrant, FastAPI pathfinding. |

## Main features

- Skill graph
- Interest clusters
- Transferable skill bridges
- Evidence strength
- Route finder
- Course nodes
- Graph filters

## Advantages

- Most scalable knowledge visualization
- Excellent for hybrid careers
- Supports DAG and taxonomy well

## Disadvantages

- Graph interactions are difficult on mobile
- Needs careful simplification and performance work

## Why this fits Future Me

It visualizes the documented career-skill-degree mappings and DAG prerequisites as a flexible network.

## Product positioning

**Category:** Skill and interest mapping platform  
**Promise:** See how one proven skill opens several education and career neighborhoods.  
**Primary CTA:** เปิดแผนที่ทักษะ  
**Voice:** Exploratory, precise, non-mystical, and explicit that links are evidence relationships.

## Distinct interaction model

Pan, zoom, filter, and connect evidence nodes; expand bridges between career clusters.

### Navigation structure

Spatial navigation: My Orbit, Evidence, Clusters, Bridges, Route.

- Desktop: A slim translucent rail over an interactive node canvas.
- Mobile: Search-first node list with an optional simplified map view.

### Core layouts

- **Homepage:** Dark immersive hero with the generated constellation and an interactive node teaser.
- **AI interview:** A compact AI sidecar asks for missing evidence while the graph updates live.
- **Dashboard:** Network canvas plus an insight drawer, saved cluster filters, and evidence coverage.
- **Results:** Three highlighted paths through the same network, each with different bridge skills.
- **Roadmap:** Graph route with prerequisite edges and alternate bridge nodes.

## Design guardrails

- Present routes as hypotheses for educational exploration, never guaranteed predictions.
- Keep private chat content separate from any parent/teacher summary.
- Keep official admissions facts, source dates, and assumptions distinguishable.
- Offer a list alternative to any graph, map, or highly visual interaction.
- Make “ยังไม่รู้” and “แก้ไขสิ่งที่ AI เข้าใจ” first-class actions.
