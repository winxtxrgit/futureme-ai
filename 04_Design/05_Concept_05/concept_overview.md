# QuestMap — แผนที่ภารกิจค้นหาตัวตน

## Concept snapshot

| Item | Direction |
|---|---|
| **Concept name** | QuestMap / แผนที่ภารกิจค้นหาตัวตน |
| **One-sentence description** | Students unlock insight by completing short, varied missions across a playful map—not by chasing a score. |
| **Main idea** | A mission-based discovery game for students who learn through action. |
| **Target user group** | Thai students in ป.6–ม.3, especially those disengaged by long questionnaires. |
| **Main user problem** | Traditional guidance feels passive, school-like, and disconnected from actual behavior. |
| **Unique value proposition** | Try before you decide: every mission reveals a new clue about how you like to work. |
| **Emotional experience** | Playful, brave, curious, and proud of progress. |
| **Visual direction** | Tactile 2.5D islands, bright tropical palette, mission badges, and rounded map controls. |
| **Development difficulty** | High |
| **Recommended technology** | Next.js/PWA, lightweight game state, mission rules engine, animation library, FastAPI evaluation, content CMS. |

## Main features

- Mission zones
- Scenario sandbox
- Evidence backpack
- No-loss progress
- Route clues
- Team missions
- Counselor safety route

## Advantages

- Strong engagement for younger students
- Makes multi-evidence assessment tangible
- Great hackathon demo

## Disadvantages

- Gamification can trivialize serious choices
- Requires ongoing mission content production

## Why this fits Future Me

It foregrounds the source-backed Scenario Missions phase and supports exploration before commitment.

## Product positioning

**Category:** Gamified self-discovery journey  
**Promise:** Try before you decide: every mission reveals a new clue about how you like to work.  
**Primary CTA:** เริ่มภารกิจแรก  
**Voice:** Energetic, friendly, low-pressure, and never competitive.

## Distinct interaction model

Choose a zone, complete a 3–5 minute scenario, collect evidence badges, and unlock route clues.

### Navigation structure

World-map navigation: Base Camp, Zones, Backpack, Routes, Team.

- Desktop: Map header with current zone and compact mission inventory.
- Mobile: Game-like bottom dock with a central Continue mission button.

### Core layouts

- **Homepage:** Playful map hero with zone previews, mission duration chips, and one prominent Continue journey control.
- **AI interview:** A friendly guide asks short questions between missions; responses alter the next challenge.
- **Dashboard:** Base Camp shows current quest, evidence backpack, streak-free progress, and route clues.
- **Results:** Route cards appear as unlocked regions with evidence badges and a Try next action.
- **Roadmap:** A map trail of missions and milestones rather than a formal Gantt-like plan.

## Design guardrails

- Present routes as hypotheses for educational exploration, never guaranteed predictions.
- Keep private chat content separate from any parent/teacher summary.
- Keep official admissions facts, source dates, and assumptions distinguishable.
- Offer a list alternative to any graph, map, or highly visual interaction.
- Make “ยังไม่รู้” and “แก้ไขสิ่งที่ AI เข้าใจ” first-class actions.
