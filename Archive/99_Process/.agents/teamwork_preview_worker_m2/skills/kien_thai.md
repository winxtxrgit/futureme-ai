# kien-thai Local Skill Dump

Core methodology:
1. Frame 1: Topic-comment over subject-verb-object.
2. Frame 2: Condition, time, and frame go first.
3. Frame 3: Sentence boundaries via space and paragraph, not period.
4. Frame 4: Closure via sentence-final particles.
5. Frame 5: Cohesion via zero anaphora and demonstratives.
6. Frame 6: Pacing via ก็.
7. Frame 7: Pivots via question, demonstrative, or simple แต่.
8. Avoid AI cliché words and robotic phrasing.
