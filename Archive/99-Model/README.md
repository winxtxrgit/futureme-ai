# FutureMe Mascot Kit

This folder is a starter package for prototyping the FutureMe mascot before committing to final production assets.

## Files

- `SKILL.md` — project-specific rules for AI/design/coding agents.
- `PROMPT.md` — master prompt for creating the full mascot lab inside the FutureMe repository.
- `index.html` — standalone interactive browser prototype.

## Try it

Open `index.html` in a browser. No build step is required.

The HTML prototype intentionally uses CSS shapes so emotion/pose/state behavior can be tested first. Replace the visual layer later with SVG, Rive, or GLB while preserving the same state API.
