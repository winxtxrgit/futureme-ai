# 4 · การจัดการคำตอบที่ขัดแย้งกัน

> ส่วนหนึ่งของ [การออกแบบแบบสำรวจปรับตัว](README.md)

---

## 4.1 หลักการ

> **ความขัดแย้งไม่ใช่ความผิดพลาดของผู้เรียน และไม่ใช่สัญญาณว่าข้อสรุปก่อนหน้าผิด**

เมื่อคำตอบสองข้อขัดกัน ระบบมีสมมติฐาน 6 แบบ และหน้าที่ของมันคือ **หาว่าอันไหนจริง** ไม่ใช่เลือกฝ่าย

| # | สมมติฐาน | ถ้าจริง ควรทำอะไร |
|---|---|---|
| H1 | เข้าใจคำถามก่อนหน้าผิด | ถามโครงสร้างเดิม ถ้อยคำใหม่ที่รูปธรรมกว่า |
| H2 | ชอบเฉพาะบาง facet ไม่ใช่ทั้งมิติ | แยก facet |
| H3 | ชอบกิจกรรม แต่ไม่ชอบสภาพแวดล้อม | ถามเรื่องสภาพแวดล้อมแยกจากกิจกรรม |
| H4 | ชอบความคิดของมัน แต่ไม่ชอบงานจริง | ถามงานจริงที่ต้องลงเวลา |
| H5 | ยังไม่แน่ใจจริง ๆ | ยอมรับ บันทึกความมั่นใจต่ำ หยุดถาม |
| H6 | **ไม่ขัดแย้ง — เป็นโปรไฟล์ความสอดคล้องต่ำ** | ถามข้อบูรณาการ ไม่ใช่ข้อคลี่คลาย |

H6 เป็นข้อที่ระบบทั่วไปมองข้าม และเป็นข้อที่มาจากเอกสารของทีมเอง — ดู §4.5

## 4.2 ตัวตรวจจับ — อะไรนับว่าขัดแย้ง

```
detectContradiction(state) → Contradiction[]
```

| ชนิด | เงื่อนไข | สมมติฐานที่ต้องทดสอบ |
|---|---|---|
| `within-dimension` | ในมิติเดียวกัน มีคำตอบ ≥4 และ ≤2 อย่างน้อยหนึ่งคู่ | H1 H2 H3 H4 |
| `format-flip` | ข้อกิจกรรมตอบบวก แต่ข้อสถานการณ์บนโครงสร้างเดียวกันตอบลบ | H4 (แรง) H1 |
| `reverse-fail` | ข้อปกติกับข้อกลับด้านในมิติเดียวกันไปทางเดียวกัน | H1 (แรง) — อาจตอบโดยไม่อ่าน |
| `efficacy-gap` | ความสนใจสูง แต่ความมั่นใจต่ำมาก | **ไม่ใช่ความขัดแย้ง** — ดู §4.6 |
| `opposite-pair-high` | คู่ตรงข้ามบนหกเหลี่ยมสูงทั้งคู่ (R-S, I-E, A-C) | H6 |
| `flat-profile` | ทุกมิติอยู่ในช่วงแคบ ไม่มีอะไรโดด | ไม่ใช่ความขัดแย้ง — เป็น low differentiation |

**`reverse-fail` สำคัญกว่าที่ดู** ถ้าผู้เรียนตอบ "ชอบ" ทั้งข้อปกติและข้อกลับด้าน
แปลว่าน่าจะกดผ่านไปโดยไม่อ่าน คำตอบทั้งชุดในมิตินั้นจึงต้องลดน้ำหนัก
นี่เป็นตัวคุมคุณภาพการตอบที่ **คลังเดิมทำไม่ได้เลย เพราะไม่มีข้อกลับด้านแม้แต่ข้อเดียว** (ทั้ง 30 ข้อเป็น positive)

## 4.3 การเลือกข้อคลี่คลาย

เมื่อเจอ `within-dimension` หรือ `format-flip` ระบบถามตามลำดับนี้ **ไม่เกิน 2 ข้อต่อความขัดแย้งหนึ่งเรื่อง**

### ขั้นที่ 1 — แยก facet ก่อนเสมอ (H2)

เพราะเป็นสมมติฐานที่เป็นจริงบ่อยที่สุดและตรวจถูกที่สุด

```
CHK-FACET-{dim}
"เมื่อกี้คุณบอกว่าชอบ {กิจกรรม A} แต่ไม่ชอบ {กิจกรรม B}
 ทั้งสองอย่างอยู่ในกลุ่มเดียวกัน อันไหนใกล้กับที่คุณคิดมากกว่า"

 ก) ชอบ {A} จริง ส่วน {B} ไม่ใช่แนวเลย
 ข) ชอบทั้งสองอย่าง แต่ {B} อธิบายไม่ตรงกับที่ผมเข้าใจ
 ค) ไม่ชอบทั้งสองอย่าง เมื่อกี้ตอบพลาด
 ง) ขึ้นกับว่าทำกับใครหรือทำที่ไหน
```

ผลลัพธ์: ก → H2 จริง เก็บ facet A ปิดเฉพาะ facet B · ข → H1 · ค → แก้คำตอบเดิม · **ง → ไปขั้นที่ 2**

### ขั้นที่ 2 — แยกกิจกรรมจากสภาพแวดล้อม (H3)

ยิงเมื่อขั้นที่ 1 ตอบ "ง" หรือเมื่อผู้เรียนตอบบวกที่กิจกรรมและลบที่สถานการณ์

```
CHK-ENV-{dim}
"ถ้างานเดิมนี้ แต่เปลี่ยนที่ทำ อันไหนที่คุณยังอยากทำ"

 ก) ทำคนเดียวเงียบ ๆ
 ข) ทำเป็นทีมเล็ก
 ค) ทำที่มีคนเยอะ ๆ ตลอดเวลา
 ง) ไม่อยากทำเลยไม่ว่าที่ไหน
```

ผลลัพธ์: ก/ข/ค → H3 จริง กิจกรรมยังใช้ได้ บันทึก `environment` แยก · ง → หลักฐานลบยืนยันแล้ว

**ทำไมข้อนี้สำคัญ** ผู้เรียนที่ชอบ `S.teach` แต่กลัวการยืนหน้าห้อง ไม่ใช่คนที่ไม่ชอบสอน
เป็นคนที่ชอบสอนแบบตัวต่อตัว ซึ่งเป็นคนละเส้นทางแต่ยังอยู่ใน S

### ขั้นที่ 3 — แยกความคิดจากงานจริง (H4)

ยิงเมื่อพบ `format-flip` โดยตรง

```
CHK-REAL-{dim}
"สมมติต้องทำ {กิจกรรม} จริง ๆ วันเสาร์ ตั้งแต่เช้าถึงบ่าย และไม่มีใครเห็นว่าคุณทำ
 คุณจะยังอยากทำไหม"

 ก) อยาก ทำได้เต็มวัน
 ข) อยาก แต่ไม่นานเท่านั้น
 ค) ไม่อยาก ชอบแค่ฟังคนอื่นทำ
```

องค์ประกอบสามอย่างในถ้อยคำนี้ตั้งใจทั้งหมด: **เวลาจริง** · **วันหยุด** (ต้องแลกกับสิ่งที่อยากทำ) · **ไม่มีใครเห็น** (ตัดแรงจูงใจเรื่องภาพลักษณ์)

ผลลัพธ์: ก → ความชอบทนต่อการลงเวลา เพิ่มความมั่นใจ · ข → ชอบระดับกลาง · ค → H4 จริง ลดน้ำหนักข้อบวกเดิม

## 4.4 ถ้าคลี่ไม่ออก

ถ้าถามครบ 2 ข้อแล้วยังขัดกัน → **หยุด** และบันทึก

```
{ dimension: "S", status: "unresolved-mixed", confidence: 0.30 }
```

ระบบ **ไม่ถามข้อที่สาม** และ **ไม่เลือกฝ่าย**

สิ่งที่แสดงกับผู้เรียนคือ

> "คำตอบของคุณเรื่องการทำงานกับคนยังไปสองทาง — บางอย่างชอบ บางอย่างไม่ชอบ
> ซึ่งเป็นเรื่องปกติมากในวัยนี้ ทางนี้จึงยังบอกไม่ได้ชัด ลองไปทำกิจกรรมสักอย่างแล้วกลับมาตอบใหม่ได้"

**นี่คือคำตอบที่ถูก** ไม่ใช่ความล้มเหลวของระบบ
ผลิตภัณฑ์นี้มีหลักว่าปฏิเสธดีกว่าเดา และหลักนั้นใช้กับแบบสำรวจด้วย

## 4.5 กรณีพิเศษ — คู่ตรงข้ามสูงทั้งคู่ (H6)

**นี่ไม่ใช่ความขัดแย้ง** และการปฏิบัติกับมันเหมือนความขัดแย้งคือความผิดพลาด

`holland_riasec_analysis.md` ระบุว่าในอดีตวงการจิตวิทยาอาชีพตีความรหัสขัดแย้งว่าเป็น
"ข้อบกพร่องเชิงการวัดผล" หรือ "ผู้ตอบสับสนในตนเอง"
แต่การวิเคราะห์ปัจจุบันพบว่าเป็น **บุคลิกภาพที่ซับซ้อนสูง** หรือ **ผู้มีความสามารถข้ามสายงาน**
ซึ่งถ้าแนะแนวถูก จะเป็นกลุ่มที่สร้างนวัตกรรมข้ามสายได้

| คู่ | แรงที่ขัดกัน | สาขาบูรณาการที่เอกสารระบุ |
|---|---|---|
| **R ↔ S** | สิ่งของ vs คน | ศัลยกรรม · **กายภาพบำบัดและเวชศาสตร์ฟื้นฟู** · วิศวกรรมชีวการแพทย์ |
| **I ↔ E** | ความจริงเชิงทฤษฎี vs ผลลัพธ์เชิงพาณิชย์ | นักวิเคราะห์การลงทุน deep-tech · บริหาร R&D สู่การพาณิชย์ · ที่ปรึกษาเชิงปริมาณ |
| **A ↔ C** | อิสระ vs โครงสร้าง | **UX/UI และ design system** · กฎหมายทรัพย์สินทางปัญญา · BIM |

**ระบบทำอะไร** ถาม **ข้อบูรณาการ 1 ข้อ** ที่ให้ทั้งสองแรงอยู่ในกิจกรรมเดียว

```
CHK-INTEG-RS
"งานที่ใช้เครื่องมือและมือของคุณเอง เพื่อช่วยให้คนกลับมาเดินได้
 — เช่น นักกายภาพบำบัดที่ใช้อุปกรณ์ฟื้นฟูกับคนไข้"
 [สเกล 5 ระดับ]
```

**ถ้าตอบ 4–5** → ยืนยัน H6 บันทึก `profileConsistency: "low"` ซึ่ง **ไม่ใช่คำตำหนิ**
และเปิดทั้งสองมิติไว้ พร้อมให้น้ำหนักเส้นทางที่ผสมทั้งสอง
(ในแคตตาล็อก 12 เส้นทาง `university-medtech-rehab` คือกรณี R-S พอดี)

**ถ้าตอบ 1–2** → ทั้งสองแรงอยู่ร่วมกันในกิจกรรมเดียวไม่ได้สำหรับผู้เรียนคนนี้ → กลับไปใช้กระบวนการคลี่คลายปกติ §4.3

**ที่สำคัญ** ข้อบูรณาการต้องไม่นับเป็นคะแนนของมิติใดมิติหนึ่ง — มันวัดความเข้ากันได้ของสองแรง ไม่ใช่ความชอบมิติเดียว

## 4.6 กรณีที่ดูเหมือนขัดแย้งแต่ไม่ใช่ — ความสนใจสูง ความมั่นใจต่ำ

```
interest[d] สูง   +   selfEfficacy[d] ต่ำ
```

นี่คือ **ผู้เรียนที่อยากลองแต่กลัวว่าจะทำไม่ได้** — ซึ่งเป็นสภาพปกติของคนอายุ 14 ที่ยังไม่เคยทำ

**ห้ามตีความว่าไม่เหมาะ** และห้ามลดคะแนนความสนใจ

รายงานตรวจสอบระบุตรงตัวว่ากลุ่ม *ความสนใจต่ำ + ความมั่นใจต่ำ* ห้ามกรองออก เพราะอาจเป็นสิ่งที่ยังไม่เคยสัมผัส
กรณี *สนใจสูง + มั่นใจต่ำ* ยิ่งต้องไม่กรอง — มันคือกลุ่มที่ได้ประโยชน์จากการแนะแนวมากที่สุด

**ระบบทำ** บันทึกเป็นข้อสังเกตแยก และแสดงเป็น

> "คุณสนใจด้านนี้ชัดเจน แต่ยังไม่มั่นใจว่าทำได้ — สองอย่างนี้ไม่เกี่ยวกัน
> ความมั่นใจมาจากการได้ลอง ไม่ใช่จากการมีพรสวรรค์มาก่อน"

พร้อมเสนอ **ภารกิจทดลองสั้น** ตามที่รายงานแนะนำ

**ห้ามเรียกความมั่นใจว่าทักษะ** — รายงานระบุว่า `Self-efficacy ถูกเรียก Skill Bridge` เป็นข้อผิดระดับสูง
ความมั่นใจสูงไม่พิสูจน์ว่ามีทักษะสูง และทักษะต้องมาจากผลงาน เกรด หรือแบบทดสอบ

## 4.7 งบสำหรับการคลี่คลาย

| ขีดจำกัด | ค่า | เหตุผล |
|---|---|---|
| ข้อคลี่คลายต่อความขัดแย้งหนึ่งเรื่อง | **2** | ถ้าสองข้อยังไม่พอ ข้อที่สามก็ไม่พอ |
| ความขัดแย้งที่คลี่ต่อหนึ่งมิติ | **2** | เกินนั้นแปลว่ามิตินี้ปนกันจริง |
| ข้อคลี่คลายรวมทั้งชุด | **5** | กันการที่แบบสำรวจกลายเป็นการสอบสวน |
| ความขัดแย้งเรื่องเดิมยิงซ้ำ | **ห้าม** | `contradictionId` ถูกบันทึก ยิงแล้วไม่ยิงอีก |

ข้อสุดท้ายคือ **ตัวกันวนไม่จบตัวจริง** — ความขัดแย้งแต่ละเรื่องมีตัวระบุที่คำนวณจากคู่ข้อที่ขัดกัน
เมื่อยิงข้อคลี่คลายไปแล้ว ตัวระบุนั้นเข้ารายการที่ไม่ยิงอีก แม้จะตรวจเจอเงื่อนไขเดิมอีกครั้ง
