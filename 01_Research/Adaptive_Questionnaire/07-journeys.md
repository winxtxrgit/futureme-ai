## 7.4 เส้นทางย่อ · จุดตัดสินที่สำคัญ

### ก · "ไม่ชอบอย่างยิ่ง" ที่ปิดสาขาไม่ได้

```
ข้อ 4   INT-S-04  "ดูแลเด็กเล็กหรือผู้สูงอายุ"          → 1
        pruneCandidate[S] = 1
        §3.3 ยังไม่ครบ (ต้องมี 2 ข้อ จาก facet ต่างกัน)
        → เข้าคิวข้อยืนยัน facet อื่น + รูปแบบต่าง

ข้อ 9   INT-S-07  "อธิบายเรื่องยากให้คนที่ยังไม่รู้เข้าใจ"  → 5
        S.teach แรง · มีคำตอบ 5 ในมิติ S แล้ว
        → §3.3 ข้อ 4 ไม่ผ่านถาวร · S ปิดไม่ได้อีกเลย
        → S = deep แทน
```

**ถ้าระบบปิด S ที่ข้อ 4** ผู้เรียนคนนี้จะไม่เห็นเส้นทางครูหรือเส้นทางฝึกอบรมเลย
ทั้งที่ชอบการสอนอย่างชัดเจน — ชอบช่วยคน แต่ไม่ชอบงานดูแลร่างกาย ซึ่งเป็นสองอย่างที่ต่างกัน

### ข · ตอบผ่าน ๆ ที่ถูกจับได้

```
ข้อ 6   INT-C-05  "ทำงานตามขั้นตอนอย่างเคร่งครัด"        → 5
ข้อ 14  INT-C-R1  "เริ่มงานโดยไม่รู้ขั้นตอน แล้วค่อยหาทาง" → 5
        (reverseCounterpart ของกันและกัน)
        → reverse-fail
        → ลดน้ำหนักคำตอบทั้งมิติ C ลงครึ่ง
        → เข้าคิวข้อ C ใหม่ในรูปแบบสถานการณ์ (SCN-03)
        → ถ้ายังขัดกัน: C = unresolved-mixed · confidence 0.30 · ไม่เลือกฝ่าย
```

**นี่คือกลไกที่คลังปัจจุบันของแอปทำไม่ได้เลย** เพราะทั้ง 30 ข้อเป็น `direction: "positive"`
ผู้เรียนที่กด 5 ทุกข้อจะได้โปรไฟล์ "สูงทุกมิติ" ที่ดูเหมือนมีความหมาย แต่ไม่มี

### ค · ชอบความคิด ไม่ชอบงานจริง

```
ข้อ 3   INT-I-02  "ทำการทดลองในห้องปฏิบัติการ"          → 5
ข้อ 11  SCN-02    วันเสาร์ว่าง → เลือก "ซ่อมหรือประกอบของ" (R)  ไม่ใช่ I
        → format-flip
        → CHK-REAL-01 เติมช่อง {A} = "ทำการทดลองในห้องปฏิบัติการ"
           "…วันเสาร์ เช้าถึงบ่าย และไม่มีใครเห็นว่าคุณทำ"
        → ตอบ "ไม่อยาก ชอบแค่ฟังคนอื่นทำ"
        → H4 จริง · ลดน้ำหนักข้อ 3 · I ไม่ถูกปิด แต่ไม่ขึ้นเป็นอันดับ 1
        → R ที่มาจาก SCN-02 ได้น้ำหนักตามจริง
```

องค์ประกอบสามอย่างในถ้อยคำ — **เวลาจริง · วันหยุด · ไม่มีใครเห็น** — คือสิ่งที่ทำให้ข้อนี้แยกความชอบจริงจากภาพลักษณ์ได้
ตัดข้อใดข้อหนึ่งออก ข้อนี้ก็กลายเป็นข้อความสนใจธรรมดาอีกข้อ

## 7.5 สิ่งที่เส้นทางเหล่านี้ยังพิสูจน์ไม่ได้

| พิสูจน์ได้ | พิสูจน์ไม่ได้ |
|---|---|
| กฎไม่ขัดกันเองในเคสเหล่านี้ | ว่ากฎให้ผลถูกกับผู้เรียนจริง |
| ความยาวอยู่ในช่วง 18–34 | ว่าความยาวนี้พอดีกับสมาธิของเด็กจริง |
| ระบบไม่ปิดสาขาจากคำตอบเดียว | ว่าเกณฑ์ 0.75 และ 0.03 ตั้งไว้ถูก |
| ข้อกลับด้านจับการตอบผ่าน ๆ ได้ในทางตรรกะ | ว่าข้อกลับด้านแต่ละข้อวัดมิติเดิมจริง (ต้องรอ CFA) |

**ขั้นถัดไปที่ต้องทำก่อนใช้กับเด็กจริง** จำลองผู้ตอบสังเคราะห์หลายพันคนผ่านกฎชุดนี้
เพื่อหาเส้นทางที่ยาวเกิน 34 สั้นกว่า 18 หรือวนในสถานะที่ไม่คาดคิด — รายละเอียดใน [`08-implementation-notes.md`](08-implementation-notes.md)
