## สิ่งที่ยังยืนยันไม่ได้

หน้า NDLP ไม่แสดงเนื้อหาที่ตัวตรวจอ่านได้ จึงยังไม่มีหลักฐานสาธารณะเพียงพอสำหรับ:

- รายการโมดูลและสถาปัตยกรรมระบบ
- RIASEC/self-discovery module
- API, schema, OAuth/SSO หรือ webhook
- จำนวนผู้ใช้และ SLA
- ข้อสรุปว่าระบบเดิมเป็น static quiz หรือไม่มีระบบจำลอง

ข้อความเหล่านี้ต้องเก็บเป็น `unverified` ไม่ใช่ข้อเท็จจริงสำหรับ pitch.

## ข้อมูลที่ต้องขอเพื่อเชื่อมจริง

API documentation, identity protocol, data owner/controller roles, sandbox, rate limits, consent model สำหรับผู้เยาว์, security review, data retention และหนังสืออนุญาต/ข้อตกลงความร่วมมือ
