# DEEP และสมมติฐานการเชื่อมระบบ

> สถานะ: ข้อมูลนโยบายบางส่วน verified; การเชื่อมระบบเป็น hypothesis  
> ตรวจล่าสุด: 24 กรกฎาคม 2026

เอกสารกระทรวงศึกษาธิการในช่วงเริ่มโครงการอธิบาย DEEP ว่าเป็นแพลตฟอร์มเพื่อรวบรวมเนื้อหา การเรียนการสอน และการพัฒนาทักษะสำหรับครู นักเรียน และผู้เรียนวัยทำงาน เพื่อสนับสนุน upskill/reskill และการเรียนรู้ตลอดชีวิต

แหล่ง: [กระทรวงศึกษาธิการ — แนวคิด DEEP](https://www.moe.go.th/%E0%B8%A3%E0%B8%A1%E0%B8%8A-%E0%B8%A8%E0%B8%98-%E0%B8%81%E0%B8%99%E0%B8%81%E0%B8%A7%E0%B8%A3%E0%B8%A3%E0%B8%93-%E0%B8%A7%E0%B8%B4%E0%B8%A5%E0%B8%B2%E0%B8%A7%E0%B8%B1%E0%B8%A5%E0%B8%A2/)

หน้า DEEP เข้าถึงไม่ได้ในตัวตรวจครั้งนี้ จึงยังไม่ยืนยันว่า:

- DEEP เป็น SSO ปัจจุบันสำหรับผู้ใช้ทั่วประเทศ
- มีบัญชี `@obec.mail.go.th`/`@deep.go.th` สำหรับทุกคน
- เชื่อม Google Workspace และ Microsoft 365 ในรูปแบบที่เอกสารเดิมวาด
- มีผู้ใช้หลายล้านคน
- เปิด API ให้โครงการภายนอก

## แนวทางสำหรับ FutureMe

วาด integration เป็น “future option” เท่านั้น:

`FutureMe standalone MVP → security/privacy review → official sandbox/API → pilot with limited data → production partnership`
