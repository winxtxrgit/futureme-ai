# กลุ่มอาชีพด้านดิจิทัล ซอฟต์แวร์ และข้อมูล (Digital, Software & Data Careers)

> สถานะ: ตัวอย่าง mapping ที่ยังต้องตรวจรายอาชีพกับ O*NET/ESCO และตลาดงานไทย  
> รายการทักษะคือ “ตัวอย่างที่เกี่ยวข้อง” ไม่ใช่ข้อกำหนดตายตัว และเส้นทางเรียนเป็นทางเลือก ไม่ใช่ทางเข้าเพียงทางเดียว

---

## 1. อาชีพ: Software Engineer / Web Developer (นักพัฒนาซอฟต์แวร์)

* **คำอธิบายงาน:** ออกแบบ เขียนโค้ด ทดสอบ และดูแลระบบแอปพลิเคชัน เว็บไซต์ หรือซอฟต์แวร์องค์กร
* **เส้นทางสายการเรียนและคณะที่เกี่ยวข้อง:**
  * **ม.ปลาย:** สายวิทย์–คณิต หรือ ศิลป์–คำนวณ (ที่ฝึก Coding)
  * **อาชีวะ:** ปวช./ปวส. สาขาเทคโนโลยีสารสนเทศ หรือ คอมพิวเตอร์ธุรกิจ
  * **มหาวิทยาลัย:** คณะวิศวกรรมศาสตร์ (คอมพิวเตอร์), คณะวิทยาศาสตร์ (วิทยาการคอมพิวเตอร์), คณะเทคโนโลยีสารสนเทศ (IT)
* **ตัวอย่างทักษะเฉพาะทางที่เกี่ยวข้อง:**
  * Programming Languages: JavaScript/TypeScript, Python, Java, Go, C#
  * Frontend/Backend Frameworks: React, Next.js, Node.js, FastAPI, Spring Boot
  * Database & Infrastructure: SQL, PostgreSQL, MongoDB, Git, Docker, Cloud (AWS/Azure)
* **ตัวอย่างทักษะการทำงานที่เกี่ยวข้อง:** Analytical Thinking, Logical Reasoning, Problem-Solving, Team Collaboration

---

## 2. อาชีพ: Data Scientist / Data Analyst (นักวิทยาศาสตร์/นักวิเคราะห์ข้อมูล)

* **คำอธิบายงาน:** รวบรวม ทำความสะอาด วิเคราะห์ข้อมูลขนาดใหญ่ (Big Data) และสร้างโมเดลทำนายผล เพื่อช่วยองค์กรตัดสินใจทางธุรกิจ
* **เส้นทางสายการเรียนและคณะที่เกี่ยวข้อง:**
  * **ม.ปลาย:** สายวิทย์–คณิต หรือ ศิลป์–คำนวณ
  * **มหาวิทยาลัย:** คณะวิทยาศาสตร์ (สถิติ, วิทยาการข้อมูล), คณะพาณิชยศาสตร์และการบัญชี (สถิติธุรกิจ), คณะวิศวกรรมศาสตร์ (คอมพิวเตอร์/ดาต้า)
* **ตัวอย่างทักษะเฉพาะทางที่เกี่ยวข้อง:**
  * Python, R, SQL, Pandas, NumPy, Scikit-learn
  * Data Visualization: Tableau, PowerBI, Looker Studio
  * Statistics, Machine Learning, Hypothesis Testing
* **ตัวอย่างทักษะการทำงานที่เกี่ยวข้อง:** Business Acumen, Critical Thinking, Storytelling with Data

---

## 3. อาชีพ: UX/UI Designer (นักออกแบบประสบการณ์และอินเทอร์เฟซผู้ใช้)

* **คำอธิบายงาน:** วิจัยพฤติกรรมผู้ใช้ ออกแบบ โครงสร้างหน้าตาแอปพลิเคชัน (Wireframe/Prototype) ให้ใช้งานง่ายและสวยงาม
* **เส้นทางสายการเรียนและคณะที่เกี่ยวข้อง:**
  * **ม.ปลาย:** ทุกสายการเรียน (วิทย์-คณิต / ศิลป์-คำนวณ / ศิลป์-ภาษา)
  * **อาชีวะ:** ปวช./ปวส. สาขาคอมพิวเตอร์กราฟิก หรือ ดิจิทัลมีเดีย
  * **มหาวิทยาลัย:** คณะสถาปัตยกรรมศาสตร์ (ออกแบบสนเทศ/ไอที), คณะเทคโนโลยีสารสนเทศ, คณะศิลปกรรมศาสตร์ (นิเทศศิลป์/มัลติมีเดีย)
* **ตัวอย่างทักษะเฉพาะทางที่เกี่ยวข้อง:** Figma, Adobe XD, Wireframing, User Research, Usability Testing, HTML/CSS พื้นฐาน
* **ตัวอย่างทักษะการทำงานที่เกี่ยวข้อง:** User Empathy, Creative Problem Solving, Active Listening, Communication
