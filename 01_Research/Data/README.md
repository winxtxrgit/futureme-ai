# คลังความรู้ FutureMe AI

> ตรวจล่าสุด: 24 กรกฎาคม 2026  
> สถานะ: ผ่านการตรวจแหล่งอ้างอิงรอบแรกแล้ว แต่ยังไม่ใช่ชุดข้อมูลที่ “ถูกต้อง 100%”  
> ก่อนนำไปใช้กับ RAG ให้ทำตามกติกาใน [`RAG_DATA_SPEC.md`](RAG_DATA_SPEC.md) และดูข้อจำกัดใน [`SOURCE_AUDIT.md`](SOURCE_AUDIT.md)

คลังนี้รวมข้อมูล 6 หมวดสำหรับสร้างระบบแนะแนวเส้นทางเรียน–อาชีพ:

1. สถิติการเรียนและงานไม่สอดคล้อง
2. หลักสูตรและช่องทางสมัครเรียนต่อของไทย
3. อาชีพ–ทักษะ–เส้นทางการเรียน
4. กรอบการสนทนาเพื่อค้นหาความสนใจและหลักฐานจากประสบการณ์
5. ข้อมูลสาธารณะเกี่ยวกับ NDLP/DEEP
6. ข้อมูลสาธารณะเกี่ยวกับ AIS Cloud/Open API และแบบจำลอง roadmap

ไฟล์สำหรับ ingest:

- `metadata/sources.jsonl` — ทะเบียนแหล่งที่ผ่านการจัดสถานะ 25 รายการ
- `metadata/quarantine_unverified.jsonl` — claim ที่ผิด ตีความคลาดเคลื่อน หรือยังพิสูจน์ไม่ได้ 16 รายการ; ห้ามเข้า production RAG

## สิ่งที่แก้จากชุดเดิม

- ถอนตัวเลขที่หาแหล่งตรงไม่ได้ เช่น mismatch ไทย 68.6%, ประกาศงาน 304,378 ตำแหน่ง, งาน 63–65% ต้องมีประสบการณ์, entry-level 22%, wage penalty 15–20%, burnout 2.5 เท่า และ GDP loss 6–8%
- แก้ความหมายข้อมูล ILO: 56% คือสัดส่วนการจ้างงานโลกที่ประเทศตัวอย่างครอบคลุม ไม่ใช่อัตรา mismatch โลก
- เปลี่ยนจากหน้าแรกขององค์กรเป็นลิงก์ตรงถึงรายงาน/ฐานข้อมูล
- อัปเดต myTCAS เป็น TCAS70 และกำหนดให้เก็บเกณฑ์รายหลักสูตร–รายปี
- ลดสถานะข้อมูล NDLP, DEEP และ AIS บางส่วนเป็น “ยังไม่ยืนยัน” เมื่อไม่มีเอกสาร API/สัญญาบริการรองรับ
- เพิ่มแบบจำลองข้อมูลสำหรับ RAG และกติกาแยก verified facts ออกจากข้อเสนอเชิงออกแบบ

## กติกาการใช้

- `verified`: มีแหล่งตรงและข้อความ/ตารางรองรับ ใช้ตอบได้พร้อม citation
- `conditional`: ถูกต้องภายใต้ปี หลักสูตร พื้นที่ หรือเงื่อนไขที่ระบุ ต้องแสดงเงื่อนไขทุกครั้ง
- `design_assumption`: แนวคิดออกแบบระบบ ยังไม่ใช่ข้อเท็จจริงภายนอก
- `unverified`: ยังตรวจไม่ได้ ห้ามส่งเข้า production RAG

ไฟล์ในหมวด 3 เป็น “ตัวอย่าง mapping” ไม่ใช่ฐานข้อมูลอาชีพครบถ้วน ควรสร้างข้อมูลจริงจาก O*NET/ESCO/TPQI และเกณฑ์รายหลักสูตรตามแบบใน `RAG_DATA_SPEC.md`.
