## สิ่งที่ตรวจพบ — และทำไมมันสำคัญกับเราบนเวที

### 1 · `tcas_and_vocational_criteria.json`

**ส่วนที่ใช้ได้ทันที** — `tcas_rounds_overview` อธิบายรอบ 1–4 ได้ถูกต้องและเป็นความรู้สาธารณะ
ไม่มีการอ้างตัวเลขรายหลักสูตร ใช้เป็นคำอธิบายให้ผู้เรียนได้เลย

**ส่วนที่ยังใช้ไม่ได้** — `featured_curriculum_catalog`

```
รายการหลักสูตร        5
มี source URL รายแถว   ไม่มี
มีวันที่ดึงข้อมูลรายแถว  ไม่มี
provenance_badge      "myTCAS70-VEC-DSL-2025"  (ระดับไฟล์)
```

ตัวเลขอย่าง `gpax_min: 3.00`, `competition_rate: "1:12"`, `tuition_per_semester_thb: 25500`
เป็นข้อมูลที่**เปลี่ยนทุกปีและต่างกันทุกคณะ** ถ้าผิดแล้วเด็กวางแผนตามจะเสียหายจริง

ปัญหาไม่ใช่ว่ามันผิด — ผมตรวจไม่ได้ว่าถูกหรือผิด **และนั่นคือปัญหา**
ป้าย `myTCAS70` บอกว่ามาจากทะเบียน แต่เราตรวจเองไปแล้วสองทางว่า

- `data.go.th` และ `data.mhesi.go.th` **ไม่มีชุดข้อมูลค่าเทอมหรือเกณฑ์รับเข้า**
- `course.mytcas.com/api/programs` เป็น catch-all คืนหน้า HTML ไม่ใช่ API

ถ้าตัวเลขมาจากการเปิดประกาศรายคณะอ่านเอง **นั่นถูกต้องสมบูรณ์** — แค่ต้องมี URL
และวันที่ต่อแถว เพื่อให้คนอื่นเปิดตามได้

### 2 · `cost_of_living_index.json`

ตัวเลขสมเหตุสมผลและใช้วางแผนได้จริง แต่มีสิ่งที่ต้องบอกก่อนติดป้าย `NSO-TDRI`:

```
BKK    4,500 + 5,500 + 2,000 + 1,500 = 13,500   ตรงกับ avg เป๊ะ
NORTH  2,800 + 3,800 +   900 + 1,000 =  8,500   ตรงเป๊ะ
NE     2,400 + 3,500 +   800 + 1,100 =  7,800   ตรงเป๊ะ
SOUTH  3,000 + 4,200 + 1,000 + 1,000 =  9,200   ตรงเป๊ะ
CENTRAL 3,200 + 4,300 + 1,100 + 1,200 = 9,800   ตรงเป๊ะ
```

**ทั้งห้าภาคผลรวมย่อยตรงกับค่าเฉลี่ยพอดี** ข้อมูลสำรวจครัวเรือนจริงไม่ลงตัวแบบนี้
นี่คือตารางที่ประกอบขึ้นจากการประมาณ ซึ่ง**ใช้ได้** ถ้าเรียกมันว่าสิ่งที่มันเป็น

**ข้อเสนอ** — เปลี่ยนป้ายจาก `TDRI-MHESI-NSO-2025` เป็น
`ประมาณการของทีม · อ้างอิงช่วงจาก TDRI/NSO · ยังไม่ผูกกับตารางต้นทาง`
แล้วผมต่อเข้าการ์ดได้ทันทีในรูป **"ค่าครองชีพภาคเหนือ ประมาณ 6,000–13,000 บาท/เดือน"**
พร้อมข้อความว่าเป็นการประมาณ
