## เรื่องที่ต้องอ่านก่อนใช้

### จุดตั้งต้นคือศูนย์กลางจังหวัด ไม่ใช่บ้านเด็ก

ระยะทางทุกตัวในไฟล์นี้วัดจาก**พิกัดศูนย์กลางจังหวัด** เด็กที่อยู่อำเภอชายแดนอาจไกลกว่าที่เขียนไว้เป็นร้อยกิโลเมตร หรือใกล้กว่ามากถ้าบ้านอยู่ติดจังหวัดข้างเคียง

ตัวเลขนี้ใช้ **เปรียบเทียบทางเลือกในภาพรวม** ได้ แต่ใช้ **วางแผนการเดินทางจริง** ไม่ได้ ถ้าจะต่อเข้าเว็บแอป ต้องรับตำแหน่งจากผู้เรียนเองแล้วคำนวณใหม่

### ระยะทางเป็นถนนจริง ไม่ใช่เส้นตรง

คำนวณด้วย OSRM ตามเส้นทางรถยนต์ ระยะเส้นตรงถูกใช้แค่ตอนคัดว่าจะถามที่ไหนบ้าง ไม่เคยถูกรายงานออกมา

`drive_minutes` เป็นเวลาขับรถโดยประมาณ **ไม่ใช่เวลาที่เด็กใช้จริง** เด็กส่วนใหญ่ขับรถยนต์ไม่ได้ ต้องรอรถสองแถวหรือรถเมล์ ซึ่งกินเวลามากกว่านี้

### ระดับการเดินทางเป็นดุลพินิจ ไม่ใช่การวัด

เส้นแบ่ง 3 / 10 / 30 / 80 กิโลเมตร เขียนไว้ใน `build/build_access.py` เพื่อให้ **เถียงได้** ไม่ใช่ซ่อนไว้ในตัวเลข ทั้งหมดตั้งบนสมมติฐานว่าเป็นการเดินทางไปกลับทุกวัน วันละสองเที่ยว โดยคนที่ยังขับรถยนต์เองไม่ได้

### `tracked` ไม่เท่ากับ `graduates`

เปอร์เซ็นต์ในไฟล์ผลลัพธ์เป็นสัดส่วนของ**ผู้ที่ติดตามได้** ไม่ใช่ของผู้สำเร็จการศึกษาทั้งหมด แถวที่ติดตามได้ต่ำกว่า 10 คนถูกระงับเปอร์เซ็นต์ทั้งหมด (เหลือแต่จำนวนดิบ) แถวที่ต่ำกว่า 30 คนติดธง `small_sample` พร้อมช่วงความเชื่อมั่น Wilson 95%

**"ศึกษาต่อ" ไม่ใช่ความล้มเหลว** การยุบผลลัพธ์ 6 ทางให้เหลือ "อัตราการมีงานทำ" จะแปลว่าคนที่เรียนต่อคือคนที่หางานไม่ได้ ซึ่งไม่จริง

### ห้ามใช้จัดอันดับ

ข้อมูลผลลัพธ์นี้ **ห้ามใช้เรียงลำดับว่าสาขาไหนหรือจังหวัดไหนดีกว่ากัน** กลไกตัดสินเส้นทางของ FutureMe เป็นกฎที่กำหนดไว้ล่วงหน้า และไม่รับส่วนแบ่งตลาดแรงงานเป็นอินพุต — ดู `00_Governance/SOURCE_POLICY.md`

## คุณภาพของพิกัด

`coord_status` บอกทุกระเบียนว่าพิกัดนั้นเชื่อได้แค่ไหน

| สถานะ | จำนวน | ความหมาย |
|---|---|---|
| `register` | 1,042 | มาจากทะเบียนโดยตรง และตกในจังหวัดที่ทะเบียนระบุ |
| `register_repaired` | 7 | ทะเบียนให้ค่าที่ไม่ใช่พิกัด กู้คืนแล้วและผ่านการตรวจ |
| `geocoded` | รวมใน `register` | หาพิกัดจากชื่อ+จังหวัดผ่าน Nominatim |
| `quarantined` | 11 | ไม่มีการตีความไหนตกในจังหวัดที่ถูกต้อง จึงไม่ใช้ |
| `missing` | 298 | ทะเบียนไม่มีพิกัด |

สถาบันที่ไม่มีพิกัด **ยังอยู่ในรายการของจังหวัดตัวเอง** เพียงแต่บอกว่าคำนวณระยะไม่ได้ การตัดทิ้งจะเท่ากับบอกเด็กจังหวัดเลยว่าที่นั่นไม่มีมหาวิทยาลัยราชภัฏ ซึ่งผิดหนักกว่าการไม่รู้ระยะทาง

### การกู้พิกัดต้องพิสูจน์ตัวเอง

พิกัดที่ผิดอันตรายกว่าพิกัดที่หายไป เพราะพิกัดที่หายไปแสดงผลว่า "ไม่ทราบ" ส่วนพิกัดที่ผิดจะให้ระยะทางและคำแนะนำการเดินทางที่ดูน่าเชื่อถือไปยังที่ที่วิทยาลัยไม่ได้ตั้งอยู่

การกู้ทุกครั้งจึงต้อง**ผ่านการตรวจ**ว่าตกในรัศมี 130 กม. จากศูนย์กลางจังหวัดที่ทะเบียนระบุเอง ตีความไหนไม่ผ่านก็ไม่ใช้ และเก็บค่าเดิมไว้ใน `coord_original`

รายการที่กู้ได้ทั้ง 7:

| อาการ | จำนวน | ตัวอย่าง |
|---|---|---|
| สลับแกน lat/lon | 3 | วิทยาลัยเทคนิคเลิงนกทา `104.5, 16.19` → `16.19, 104.5` |
| ทศนิยมหาย | 3 | วิทยาลัยสารพัดช่างพระนครศรีอยุธยา `14342124` → `14.342124` |
| เป็นพิกัด UTM zone 47N | 1 | วิทยาลัยเทคนิคกาญจนดิษฐ์ `561531, 1011654` → `9.1515, 99.5600` |

รายการสุดท้ายน่าสนใจเป็นพิเศษ เพราะพิกัดที่แปลงได้ตกที่ **อำเภอกาญจนดิษฐ์** ตรงกับชื่อวิทยาลัยพอดี

## เรื่องที่ผิดพลาดระหว่างทาง และถูกถอนออก

รอบแรกของงานนี้ดึงข้อมูลจาก OpenStreetMap ผ่าน Overpass API โดยมี mirror สำรองหลายตัว หนึ่งในนั้นคือ `overpass.osm.ch`

**`overpass.osm.ch` เป็นฐานข้อมูลเฉพาะประเทศสวิตเซอร์แลนด์** เมื่อถามถึงจังหวัดของไทย มันตอบ HTTP 200 พร้อม JSON ที่ถูกต้องตามรูปแบบ แต่มี `elements` เป็นอาร์เรย์ว่าง สคริปต์จึงบันทึกผลว่าง 15 จังหวัดเป็น cache ที่สำเร็จถาวร

**ข้อผิดพลาดจริงไม่ใช่การเลือก mirror ผิด แต่คือ retry loop ตรวจว่าการเชื่อมต่อสำเร็จ ไม่ได้ตรวจว่าคำตอบสมเหตุสมผล** — สถานะ 200 กับ JSON ที่ parse ได้ ถูกนับเป็นความสำเร็จทันที

ลายเซ็นที่ใช้จับได้คือ `osm3s.timestamp_osm_base` ของเซิร์ฟเวอร์ regional extract เป็นเลขลำดับ (`116186`) ไม่ใช่ ISO timestamp

cache ชุดนั้น**ไม่เคยถูกอ่านเข้าไฟล์ข้อมูลจริง** เพราะตัวประกอบข้อมูลอ่านจากทะเบียน สอศ. และ อว. เท่านั้น แต่เส้นทาง OSM ทั้งหมดถูกลบทิ้งแทนการซ่อม เพราะทะเบียนราชการครอบคลุมกว่าและตรวจสอบย้อนกลับได้ดีกว่าอยู่แล้ว

## สร้างซ้ำ

```bash
cd build
python3 build_institutions.py     # ทะเบียน สอศ. + อว. → institutions.json
python3 repair_coords.py          # ตรวจ กู้ และกักพิกัด
python3 build_stations.py         # Wikidata → stations.json พร้อม mode
python3 build_outcomes.py         # ผลลัพธ์อาชีวะ + small-sample guard
python3 build_access.py           # OSRM → province_access/*.json
```

`geocode_univ.py` เรียก Nominatim ที่ 1 คำขอ/วินาที ตามนโยบายการใช้งาน และ cache ผลไว้ ใช้เวลาราว 15 นาทีเมื่อรันครั้งแรก

สคริปต์ทุกตัวรันซ้ำได้โดยไม่ทำลายผลเดิม และ resume ได้เมื่อขาดกลางคัน

## ยังไม่ได้ทำ

- ยังไม่ต่อเข้าเว็บแอป และยังไม่มี knowledge record ที่อ้างชุดข้อมูลนี้
- ทางเลือกนอกจังหวัดจำกัดที่ 80 ปลายทางต่อจังหวัด ตามข้อจำกัดของ OSRM สาธารณะ จังหวัดที่มีสถาบันหนาแน่นรอบตัวจึงอาจไม่ครบ
- ไม่มีข้อมูลค่าโดยสารจริง ค่าหอพัก หรือตารางเดินรถ ซึ่งเป็นตัวแปรที่เด็กใช้ตัดสินใจจริงพอๆ กับระยะทาง
- `stations.json` มาจาก Wikidata ซึ่งครอบคลุมรถไฟฟ้าในกรุงเทพดี แต่สถานีขนส่งต่างจังหวัดมีเพียง 6 แห่ง ซึ่งน้อยกว่าความเป็นจริงมาก
