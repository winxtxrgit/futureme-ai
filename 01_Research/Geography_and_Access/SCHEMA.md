# Schema

ทุกฟิลด์ที่บอก "ความน่าเชื่อถือ" ของข้อมูลถูกเก็บไว้ในระเบียนเอง ไม่ใช่ในเอกสารแยก เพื่อให้โค้ดที่อ่านไฟล์เหล่านี้ตัดสินใจได้โดยไม่ต้องรู้บริบทเพิ่ม

---

## `provinces.json`

| ฟิลด์ | ชนิด | หมายเหตุ |
|---|---|---|
| `iso` | string | รหัส ISO 3166-2 เช่น `TH-50` · เป็นคีย์หลักที่ใช้เชื่อมทุกไฟล์ |
| `qid` | string | รหัส Wikidata |
| `en`, `th` | string | ชื่อทางการ |
| `th_short` | string | ชื่อไทยที่ตัดคำว่า "จังหวัด" ออก ใช้แสดงผล |
| `lat`, `lon` | number | พิกัดศูนย์กลางจังหวัด **ไม่ใช่ที่ตั้งศาลากลาง** |
| `population` | number \| null | จาก Wikidata ปีอ้างอิงไม่สม่ำเสมอ ใช้ดูขนาดคร่าวๆ เท่านั้น |

## `institutions.json`

| ฟิลด์ | ชนิด | หมายเหตุ |
|---|---|---|
| `id` | string | `ovec-pub-*`, `ovec-pri-*`, `mhesi-*` — คำนำหน้าบอกทะเบียนต้นทาง |
| `name_th` | string | ชื่อตามทะเบียน |
| `kind` | enum | ดูตารางด้านล่าง |
| `sector` | string | เช่น `รัฐ (สอศ.)`, `เอกชน`, `มหาวิทยาลัยในกำกับรัฐ` |
| `offers` | string[] | ระดับที่เปิดสอน อนุมานจากชื่อสถาบัน ดูข้อจำกัดด้านล่าง |
| `province_iso` | string | เชื่อกับทะเบียนได้ แม้พิกัดจะผิด |
| `district`, `subdistrict` | string \| null | มีเฉพาะระเบียนอาชีวะ |
| `lat`, `lon` | number \| null | `null` เมื่อ `coord_status` เป็น `missing` หรือ `quarantined` |
| `coord_status` | enum | `register` · `register_repaired` · `quarantined` · `missing` |
| `coord_source` | enum \| null | `register` หรือ `geocoded` |
| `coord_repair` | string | มีเมื่อซ่อมแล้ว เช่น `swapped_axes`, `utm47n_easting_northing` |
| `coord_original` | object | ค่าเดิมก่อนซ่อมหรือก่อนกัก |
| `coord_km_from_province_centre` | number | ระยะที่ใช้ยืนยันว่าการซ่อมถูกต้อง |
| `phone`, `website` | string \| null | ค่าที่ทะเบียนเขียนว่า `-` ถูกแปลงเป็น `null` |
| `source` | string | ทะเบียนและปีที่ดึง |

### `kind`

| ค่า | ระดับที่เปิด | ความหมาย |
|---|---|---|
| `technical_college` | ปวช. ปวส. | วิทยาลัยเทคนิค |
| `vocational_college` | ปวช. ปวส. | วิทยาลัยอาชีวศึกษา |
| `career_college` | ปวช. ปวส. | วิทยาลัยการอาชีพ |
| `agricultural_college` | ปวช. ปวส. | วิทยาลัยเกษตรและเทคโนโลยี / ประมง |
| `polytechnic` | ปวช. ปวส. หลักสูตรระยะสั้น | วิทยาลัยสารพัดช่าง |
| `private_vocational` | ปวช. ปวส. | อาชีวะเอกชน |
| `rajamangala` | ปวส. ปริญญาตรี | ราชมงคล — รับผู้จบ ปวส. ต่อปริญญาตรีได้ |
| `rajabhat` | ปริญญาตรี ปริญญาโท | ราชภัฏ — มีเกือบทุกจังหวัด |
| `university` | ปริญญาตรี ปริญญาโท | มหาวิทยาลัยอื่น |
| `nursing_college` | ปริญญาตรี | วิทยาลัยพยาบาล |
| `public_health_college` | ปวส. ปริญญาตรี | วิทยาลัยการสาธารณสุข |
| `arts_college` | ปวช. ปวส. | นาฏศิลป์ ช่างศิลป์ ดุริยางค์ |

> **ข้อจำกัดที่ต้องรู้:** `offers` อนุมานจาก**ชื่อสถาบัน** ไม่ใช่จากทะเบียนหลักสูตรรายแห่ง ชื่อสถาบันไทยบอกประเภทได้แม่นในระดับหนึ่ง แต่วิทยาลัยแต่ละแห่งเปิดสาขาไม่เหมือนกัน และบางแห่งเปิดระดับที่ชื่อไม่ได้บอก **ต้องตรวจกับสถานศึกษาโดยตรงก่อนใช้ตัดสินใจ**

## `stations.json`

| ฟิลด์ | ชนิด | หมายเหตุ |
|---|---|---|
| `qid` | string | รหัส Wikidata |
| `en`, `th` | string | `th` เป็น `null` ได้ |
| `lat`, `lon` | number | |
| `mode` | enum | `metro` · `rail` · `bus` · `ferry` · `air` |
| `line` | string \| null | สายที่ให้บริการ |
| `wikidata_types` | string[] | ประเภทดิบทั้งหมด เก็บไว้ให้ตรวจการจำแนกย้อนหลังได้ |

`metro` กับ `rail` แยกกันเพราะมีความหมายต่างกันสำหรับผู้เรียน — รถไฟฟ้าในเมืองทำให้ระยะ 20 กม. เป็นการเดินทางปกติ ส่วนสถานีรถไฟทางไกลมักไม่ใช่การเดินทางประจำวัน การเรียกทั้งคู่ว่า "รถไฟ" จะลบความต่างที่ผู้เรียนกำลังชั่งน้ำหนักอยู่พอดี

จุดที่ไม่ใช่ขนส่งผู้โดยสาร — ท่าเรือสินค้า ฐานทัพ คลังก๊าซ สถานีสินค้า — ถูกตัดออกแล้ว 46 จุด

## `vocational_outcomes.json`

| ฟิลด์ | ชนิด | หมายเหตุ |
|---|---|---|
| `province_iso`, `level`, `field_th` | string | `level` คือ `ปวช.` หรือ `ปวส.` |
| `graduates` | number | ผู้สำเร็จการศึกษาทั้งหมด |
| `tracked` | number | จำนวนที่การสำรวจติดตามได้ **ตัวส่วนของทุกเปอร์เซ็นต์** |
| `tracked_share` | number | `tracked / graduates` |
| `thinly_tracked` | boolean | `tracked_share < 0.30` |
| `small_sample` | boolean | `tracked < 30` |
| `percentages_suppressed` | boolean | `tracked < 10` |
| `suppression_reason` | string | มีเมื่อถูกระงับ |
| `counts_of_tracked` | object | จำนวนดิบ 7 ประเภทผลลัพธ์ **มีเสมอ แม้เปอร์เซ็นต์ถูกระงับ** |
| `of_tracked_percent` | object | ไม่มีเมื่อถูกระงับ |
| `of_tracked_percent_ci95` | object | ช่วงความเชื่อมั่น Wilson 95% `[ต่ำ, สูง]` |

ผลลัพธ์ 7 ประเภท: `ศึกษาต่อ` · `รองานหรือว่างงาน` · `ทำงานรัฐวิสาหกิจ` · `ทำงานราชการ` · `ทำงานเอกชน` · `อาชีพอิสระ` · `อื่น ๆ`

> ใช้ Wilson แทนการประมาณแบบปกติ เพราะการประมาณแบบปกติให้ค่าไร้สาระที่ขอบ — 4 จาก 4 กลายเป็น 100% ± 0% — และขอบคือที่ที่แถวเหล่านี้อยู่กันเป็นส่วนใหญ่

## `province_access/TH-xx.json`

```
{ "summary": {...}, "origin": {...}, "options": [...] }
```

### `summary`

| ฟิลด์ | หมายเหตุ |
|---|---|
| `options_total` | ทางเลือกทั้งหมดที่พิจารณา |
| `in_province` | อยู่ในจังหวัดเดียวกัน |
| `within_30km` | อยู่ในระยะที่ไปกลับได้ **นับเฉพาะที่มีพิกัด** |
| `distance_unknown` | อยู่ในจังหวัดแต่ยังคำนวณระยะไม่ได้ |
| `offers_vocational`, `offers_degree` | จำนวนที่เปิด ปวช./ปวส. และปริญญาตรี |

### `options[]`

| ฟิลด์ | หมายเหตุ |
|---|---|
| `road_km` | ระยะทางถนนจริงจาก OSRM · `null` เมื่อไม่มีพิกัด |
| `road_km_is_estimate` | `true` เมื่อ OSRM ตอบไม่ได้และใช้ระยะเส้นตรงแทน |
| `drive_minutes` | เวลาขับรถ **ไม่ใช่เวลาที่ผู้เรียนใช้จริง** |
| `band` | `walkable` · `local` · `commute` · `hard_commute` · `relocate` · `unknown_distance` |
| `band_th` | คำอธิบายที่เขียนถึงผู้เรียนโดยตรง |
| `modes_th` | พาหนะที่ใช้ได้ตามระดับ และเพิ่ม `รถไฟฟ้า`/`รถไฟ` เมื่อมีสถานีใกล้ |
| `nearest_station` | metro ในรัศมี 2 กม. หรือ rail ในรัศมี 3 กม. |
| `in_home_province` | อยู่ในจังหวัดของผู้เรียนหรือไม่ |

### เส้นแบ่งระดับ

| ระดับ | ระยะ | ความหมาย |
|---|---|---|
| `walkable` | ≤ 3 กม. | เดินหรือปั่นจักรยานไปได้ |
| `local` | ≤ 10 กม. | ไปกลับทุกวันได้ตามปกติ |
| `commute` | ≤ 30 กม. | ไปกลับได้ แต่กินเวลาและค่าเดินทางทุกวัน |
| `hard_commute` | ≤ 80 กม. | ไปกลับทุกวันเหนื่อยมาก ควรคิดเรื่องหอพักด้วย |
| `relocate` | > 80 กม. | ต้องย้ายไปอยู่ที่นั่น |

เส้นแบ่งเหล่านี้เป็น**ดุลพินิจ** เขียนไว้ใน `build/build_access.py` เพื่อให้เถียงได้ ตั้งบนสมมติฐานว่าเป็นการเดินทางไปกลับวันละสองเที่ยว โดยผู้เรียนที่ยังขับรถยนต์เองไม่ได้
